İlk kurulum

Bir kez yapılır (~10 dakika). Uygulamanın Google'a bağlanabilmesi için kendi Google Cloud projen gerekir. Her adımdaki düğme doğru sayfayı yeni sekmede açar.

Sunucu modundasın. Application type olarak Web application seç ve Authorized redirect URIs alanına şunu ekle: __REDIRECT_URI__. İndirdiğin JSON'u sunucuda youtube-hub/data/client_secret.json olarak kaydet (güvenlik gereği bu sayfadan yüklenemez).
  1. Üç API'yi aç. Her birinde mavi Enable düğmesine bas.
    YouTube Data API v3 YouTube Analytics API YouTube Reporting API
  2. Onay ekranını oluştur. Get started → uygulama adı (__APP_NAME__) ve e-postan → Audience: External → Create.
    Onay ekranını aç
  3. Yayına al. Audience → Publish app → onayla. Durum In production olmalı; yoksa bağlantılar 7 günde bir kopar.
    Audience sayfasını aç
  4. İstemci oluştur ve indir. Create client → Application type: Desktop app → Create → Download JSON.
    Clients sayfasını aç
  5. İndirdiğin dosyayı buraya bırak (genelde İndirilenler'de, adı client_secret_…json).
    Dosyayı sürükle bırak veya tıklayıp seç

Bu dosya sadece bu bilgisayarda saklanır. Kimseyle paylaşma.
